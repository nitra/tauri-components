## Огляд

Модуль визначає п’ять станів результату для показу в інтерфейсі: Pending, Done, ActionFailure, NeedsClarification і Failed. Він забезпечує узгоджене відображення очікування, завершення з підсумком і діями, запиту на уточнення та помилки виконання.

Модуль read-only: не змінює ФС або БД, але звертається до мережі. Кешування не використовується. Для мережевого бекенда використовується <http://localhost:11434>.

## Поведінка

- Pending — показує стан очікування, коли результат ще не готовий.
- Done — показує успішно завершений результат із коротким підсумком і виконаними діями.
- ActionFailure — показує частковий результат, де одна дія виконалась, а інша завершилась помилкою.
- NeedsClarification — показує запит на уточнення, коли бракує даних для продовження.
- Failed — показує помилку виконання, зокрема недоступність сервера на <http://localhost:11434>.

## Публічний API

`api`

`Pending` — фіксує запит, який ще не завершено.
`Done` — означає успішне завершення.
`ActionFailure` — показує, що потрібна дія не виконалась.
`NeedsClarification` — вказує на нестачу даних для продовження.
`Failed` — позначає остаточну помилку без подальшого продовження.

Компонент read-only: не змінює ФС або БД.
Працює через мережу та звертається до `http://localhost:11434`.
