## Огляд

Показує діалог аудиту з двома станами: `Default` відображає приклад журналу подій, а `Empty` — порожній журнал подій. Це дає окремі варіанти для перегляду стану аудиту перед підтвердженням дії.

## Поведінка

- Default — показує діалог аудиту з прикладом журналу подій і запитом на підтвердження дії.
- Empty — показує діалог аудиту з порожнім журналом подій.

## Публічний API

- Default: відображає значення за замовчуванням, коли для об’єкта немає окремо заданого вмісту; не змінює дані у ФС або БД
- Empty: відображає порожній стан для об’єкта без даних; не змінює дані у ФС або БД

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
