## Огляд

Файл описує приклади станів дій діалогу: `Default` для звичайного підтвердження, `Loading` для виконання дії із завантаженням і `Disabled` для забороненої взаємодії. Він потрібен, щоб демонструвати та перевіряти, як кнопки діалогу виглядають і поводяться в цих станах.

Файл є read-only: не записує дані у файлову систему або базу даних.

## Поведінка

- `Default` показує базовий сценарій дій діалогу з типовою активною кнопкою підтвердження.
- `Loading` показує стан виконання дії, щоб перевірити відображення завантаження.
- `Disabled` показує неактивний стан дій, щоб перевірити заборону взаємодії.

## Публічний API

- Default — показує звичайний стан компонента.
- Loading — відображає стан очікування.
- Disabled — показує недоступний для взаємодії стан.
- API є read-only: не пише у ФС/БД.
